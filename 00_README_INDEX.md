# Re.Match Permanent Reference Bundle v1.0

**Generated:** 2026-05-07  
**Status:** permanent reference set  
**Primary source:** user-provided Re.Match Official Project Definition v1.0 plus current public scientific sources.

This bundle is designed to become the stable reference spine for Re.Match: product definition, scientific foundation, mechanism map, evaluation architecture, governance boundaries, and grant/adaptation language.

## File sequence

1. `01_ReMatch_Definitive_Project_Definition_v2.0.md`  
   The canonical product/project definition. It is deliberately not written as a grant application. Use this as the stable project spine.

2. `02_ReMatch_Scientific_Foundation_White_Paper_v1.0.md`  
   A white-paper-grade synthesis of the scientific frameworks supporting Re.Match.

3. `03_ReMatch_Feature_to_Mechanism_Evidence_Map_v1.0.md`  
   A feature-by-feature evidence map linking product architecture to psychosocial, behavioral-health, reentry, and implementation mechanisms.

4. `04_ReMatch_Theory_of_Change_and_Evaluation_Framework_v1.0.md`  
   Logic model, evaluation design, pilot study plan, metrics, and implementation-science structure.

5. `05_ReMatch_Ethics_Privacy_and_Governance_Framework_v1.0.md`  
   Safety, privacy, boundaries, anti-surveillance posture, human-review model, and risk controls.

6. `06_ReMatch_Grant_and_Credit_Adaptation_Kit_v1.0.md`  
   Grant and infrastructure-credit language extracted from the core docs. This is the only file intentionally grant-facing.

7. `07_ReMatch_Research_Targets_and_Citation_Backbone_v1.0.md`  
   Deep research target list and source backbone for future literature review.

8. `ReMatch_Permanent_Reference_Bundle_v1.0.docx`  
   One combined DOCX containing the full sequence in a portable report format.

9. `ReMatch_Permanent_Reference_Bundle_v1.0.pdf`  
   PDF export of the combined DOCX for easy sharing and archiving.

## Recommended use

- Treat File 01 as the canonical project definition.
- Treat Files 02 to 05 as the scientific and governance armor.
- Treat File 06 as the adaptation layer for funders, API-credit programs, and institutional outreach.
- Treat File 07 as the next deep-research command center.

## Version discipline

When changing the product, update File 01 first. Then propagate changes into the scientific, evaluation, and grant-facing files. Do not let grant language become the canonical definition.
